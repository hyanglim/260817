## 사용자가 겪는 흐름

학생은 웹페이지에 접속해 자신의 Student ID를 입력하고 프로젝트를 시작한다. 문제정의부터 데이터 선택, 분석, 시각화, 해석, 성찰까지 단계별 질문에 답하고 각 단계에서 저장한다. 저장 후 다음 단계로 이동하며, 다시 접속하면 기존 작성 내용을 불러와 이어서 작성할 수 있다. 교사는 별도의 확인 화면에서 학생 ID를 선택해 현재 진행 단계와 작성 내용, 수정 횟수, 마지막 저장 시간을 확인한다. 학생은 모든 단계를 완료한 뒤 프로젝트 화면을 종료한다.

<summary>테스트 케이스 설계</summary>

정상
1. 학생이 유효한 Student ID를 입력하고 프로젝트 시작을 누르면 문제정의 단계가 표시되어야 한다.

2. 학생이 단계별 답변을 작성하고 저장하면 내용과 저장 시각이 기록되고, 같은 Student ID로 다시 접속하면 기존 답변을 불러와야 한다.

실패
1. Student ID를 비운 상태에서 프로젝트 시작을 누르면 “Student ID를 입력하세요”라고 알려주고 다음 화면으로 이동하지 않아야 한다.

2. 학생이 현재 단계의 답변을 비운 채 다음 단계를 누르면 “내용을 작성하거나 저장한 후 이동하세요”라고 안내하고 입력 내용이 사라지지 않아야 한다.

3. Student ID나 답변에 예상보다 지나치게 긴 값이 입력되면 화면이 깨지거나 저장에 실패하지 않아야 하며, 허용 길이를 초과한 경우 입력 가능한 범위를 안내해야 한다.
